# Design system inicial

Direção: interface clínica limpa, de alta densidade informacional sem parecer ERP antigo.

- sidebar persistente no desktop;
- cards discretos;
- agenda como cockpit operacional;
- paciente com contexto clínico agrupado;
- avisos fortes para ações destrutivas;
- informações clínicas diferenciadas de administrativas;
- mobile responsivo para consulta rápida, não para esmagar odontograma complexo em uma única coluna sem estratégia.
